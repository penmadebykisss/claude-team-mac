# Claude для команды на вашем Маке

Общий веб-чат с Claude (и другими моделями) для сотрудников: у каждого свой логин и история, администратор добавляет и отключает людей, доступ из любой точки через защищённую сеть Tailscale. Сам Мак только держит интерфейс, модель работает в облаке, поэтому хватает любого Мака, включая M1 с 8 ГБ.

Демо: https://chat.144-31-16-235.sslip.io

## Что понадобится

- Мак, который постоянно включён и подключён к сети.
- Ключ API для модели. Anthropic не принимает российские карты, поэтому варианты такие:
  - **OpenRouter** (openrouter.ai): Claude и другие модели по одному ключу, оплата картой зарубежного банка или криптовалютой. Самый простой вариант.
  - **Anthropic напрямую** (console.anthropic.com): нужна зарубежная карта.
  - **Российские посредники API** (оплата в рублях, дороже).
- Аккаунт Tailscale (бесплатно до 3 пользователей / 100 устройств) — для доступа сотрудников извне офиса.

## Установка (10–15 минут)

1. Откройте «Терминал» и выполните:
   ```bash
   bash install.sh
   ```
   Скрипт установит Homebrew, OrbStack (Docker) и чат, спросит email и пароль администратора, включит автозапуск и отключит сон Мака от сети.
2. Установите Tailscale с tailscale.com/download, войдите и запустите `bash install.sh` ещё раз — скрипт опубликует чат и выведет адрес для сотрудников.
3. Откройте http://localhost:3000, войдите администратором.
4. **Настройки администратора → Подключения → OpenAI API → «+»:**
   - OpenRouter: адрес `https://openrouter.ai/api/v1`, ключ `sk-or-...`
   - Anthropic: адрес `https://api.anthropic.com/v1`, ключ `sk-ant-...`
5. **Настройки администратора → Модели:** оставьте видимыми нужные (например, Claude Sonnet), задайте модель по умолчанию.

## Сотрудники

- **Добавить:** Настройки администратора → Пользователи → «+» → имя, email, временный пароль.
- **Подключиться:** сотрудник ставит Tailscale на свой компьютер или телефон, входит по приглашению (Tailscale → Users → Invite) и открывает адрес чата.
- **Ограничить модели:** Пользователи → Группы — каким группам какие модели доступны.
- **Отключить:** Пользователи → сотрудник → роль «Ожидает» или удалить.

## Обслуживание

- **Обновить:** `bash install.sh` (данные и настройки сохраняются).
- **Логи:** `docker logs open-webui --tail 100`.
- **Резервная копия:** `docker run --rm -v open-webui:/d -v "$PWD":/b alpine tar czf /b/open-webui-backup.tgz -C /d .`
- **Расходы:** оплачивается только фактическое использование API; баланс и лимиты — в личном кабинете OpenRouter/Anthropic.

## Если нужны полностью локальные модели

Когда данные нельзя отправлять в облако, на тот же Мак ставится Ollama и открытая модель (Qwen, Llama, Gemma); она появится в том же списке моделей. На M1 с 8–16 ГБ реалистичны модели 7–8B, на 32–48 ГБ — до ~30B. Качество ниже Claude, но данные не покидают Мак.
